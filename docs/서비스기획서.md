A. 기간
────────────────────────────────────────────
 대상 기간   월~금 (공휴일·휴원일 제외)
 주 시작     월요일
 운영 요일   월화수목금
 휴원일      설정 화면에서 원장이 직접 등록 (공휴일 + 자체 휴강 통합)

B. 출석 비율 — main 지표
────────────────────────────────────────────
 판정 방식   비율 (분모 = 그 주의 실제 운영일수)
 최고 100% / 양호 80%↑ / 보통 60%↑ / 주의 60%미만

C. 연속 출석 — sub 지표
────────────────────────────────────────────
 우수 기준   10일 이상
 끊김        언급함 (학생용·학부모용 모두, 질책 아닌 톤으로)
 신기록      강조함
 계산        휴원일은 건너뜀 (연속 유지)

D. 체류 시간 — sub 지표
────────────────────────────────────────────
 정상 기준   60분              [설정 가능]
 짧음 판정   평소 대비 60% 미만 [설정 가능]
 비교 대상   그 학생의 지난 4주 평균 [설정 가능]
 0분 처리    평균에 포함 (하원 체크도 실력)
             ※ 별도 체크율 지표 도입 여부는 S6에서 재검토
 초과 체류   칭찬으로 언급

E. 최종 등급
────────────────────────────────────────────
 최고  출석 100% + (연속 10일↑ 또는 신기록)
 양호  출석 80%↑
 보통  출석 60%↑
 주의  출석 60% 미만

 원칙  등급은 출석 비율로만 결정.
       연속·체류는 문장 재료로만 사용, 등급을 흔들지 않음.
 근거  체류 시간은 하원 체크 누락에 취약해 신뢰도가 가장 낮음.

F. 예외 처리
────────────────────────────────────────────
 기록 0건        안내 후 중단, API 호출 없음
 신입생          주차별 독립. 월요일 개시가 아니면 다음 주부터
 과거 데이터 부족 체류 비교 생략, 나머지만 생성
 통째 휴원       안내 후 중단, API 호출 없음
 학생 미선택     "학생을 먼저 선택해 주세요."
